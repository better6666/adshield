# AdShield Mobile 界面设计方案

## 产品定位

AdShield Mobile 是一款面向 Android 优先、兼容 iOS 展示体验的广告与弹窗防护工具。首版以本地设备状态管理、规则开关、白名单和拦截统计为核心；真正的系统级流量拦截需要后续接入 Android VpnService 原生模块，Expo Go 中先提供可验证的交互原型与规则模拟状态。

## Screen List

| 页面 | 主要内容与功能 |
|---|---|
| 防护首页 | 显示保护状态、今日拦截数、当前规则数量、最近拦截记录；提供一键开启/暂停保护。 |
| 规则中心 | 分组展示广告、跟踪器、弹窗和页面净化规则；支持总开关与分组开关。 |
| 白名单 | 展示已允许的网站域名；支持新增、删除和说明文案。 |
| 拦截记录 | 展示最近被拦截的域名、类型和时间；支持清空记录。 |
| 设置 | 提供启动时自动保护、通知提示、深色模式入口和关于信息。 |

## Primary Content and Functionality

首页采用单手可操作的纵向布局。顶部为品牌标识和设置入口，中部是高对比度的圆角状态卡片，使用盾牌图标、绿色状态点和“保护中/已暂停”文字表达当前状态。状态卡片下方放置大尺寸主按钮，保证拇指可触达；统计以三列小卡片呈现，避免让用户阅读长段数字。底部使用四个 Tab：防护、规则、记录、设置。

规则中心使用分组列表，每行包含规则名称、用途说明和原生 Switch。白名单页面使用搜索/输入框与域名列表，添加成功后给予轻量提示。拦截记录使用 FlatList，空状态明确说明“开启保护后，拦截记录会显示在这里”。

## Key User Flows

1. 用户打开应用，首页读取本地设置并显示当前保护状态。
2. 用户点击“开启保护”，应用更新本地状态、触发轻提示，并在 Android 原生实现接入后请求 VPN 权限。
3. 用户进入规则中心，关闭“弹窗拦截”或某个规则分组，首页统计和状态说明同步更新。
4. 用户进入白名单，输入域名并点击添加；域名被规范化后写入本地存储，并立即出现在列表中。
5. 用户进入拦截记录，查看域名、拦截类型和时间；点击清空后展示空状态。

## Color Choices

品牌主色使用深海蓝 `#0B3B60`，代表网络边界与可信防护；强调色使用青绿色 `#18B6A4`，用于开启状态和成功反馈；警示色使用琥珀色 `#F4A340`，用于暂停、规则异常或需要用户确认的状态；危险色使用珊瑚红 `#D95C5C`，仅用于删除白名单和清空记录等破坏性操作。浅色背景使用 `#F4F7FA`，卡片使用 `#FFFFFF`，正文使用 `#14202B`，次要文字使用 `#657482`。深色模式将背景切换为 `#0E1720`，卡片切换为 `#172532`，保持同一品牌色相。

## Interaction and Accessibility

所有主要按钮高度不低于 48dp，使用原生 Pressable 的按压透明度反馈；开关变化提供轻微触感反馈。文本遵循 iOS/Android 系统动态字体，状态不能只依赖颜色表达，必须同时显示图标和文字。所有列表项使用稳定 key，长列表使用 FlatList，页面内容包裹 ScreenContainer 处理刘海和底部安全区。
